## Work Completed

### NumPy
Numerical computing and array operations, including:

- Array creation, indexing, and slicing
- Mathematical operations and aggregation
- Boolean filtering and missing-value handling
- Reshaping, broadcasting, and vectorization
- Random number generation
- Basic linear algebra

### Pandas
Data manipulation and analysis, including:

- Dataset inspection and data quality checks
- Data cleaning and transformation
- Missing-value and duplicate handling
- Filtering, grouping, and aggregation
- Combining datasets
- Text and datetime operations
- Integrated data preparation workflows

### Descriptive Statistics
Statistical summaries and numerical analysis used to understand datasets and interpret their characteristics.

### Exploratory Data Analysis
Practical analysis of two datasets:

- **Titanic:** Exploring passenger characteristics, survival patterns, and relationships between variables.
- **Online Retail:** Analyzing customer behavior, purchasing patterns, sales, and revenue.
