# Descriptive Statistics

This folder contains my notes, Python practice, and exercises on **Descriptive Statistics**, an important foundation for Data Science, Exploratory Data Analysis (EDA), and Machine Learning.

The goal is to understand how to summarize data, measure its variability, identify unusual values, and interpret relationships between variables using Python and Pandas.

## Topics Covered

### 1. Measures of Central Tendency

* Mean
* Median
* Mode
* Understanding how outliers affect the mean and median

### 2. Measures of Variability

* Range
* Variance
* Standard Deviation
* Interquartile Range (IQR)

### 3. Position of Data

* Quartiles
* Percentiles
* Five-number summary
* Using `describe()` to summarize numerical data

### 4. Distribution of Data

* Frequency distributions
* Histograms and data distribution
* Symmetric, right-skewed, and left-skewed distributions
* Uniform distributions

### 5. Skewness and Outliers

* Understanding skewness
* Identifying potential outliers
* IQR method for detecting outliers
* Understanding why outliers should be investigated before removal

### 6. Relationships Between Variables

* Covariance
* Correlation
* Positive and negative relationships
* Understanding why correlation does not imply causation

### 7. Descriptive Statistics for Categorical Data

* Frequency counts using `value_counts()`
* Category proportions and percentages
* Identifying the mode
* Group-wise summaries using `groupby()`

### 8. Descriptive Statistics Using Python

* Summarizing numerical and categorical data
* Checking missing values and duplicate rows
* Calculating statistical measures using NumPy and Pandas
* Interpreting summary statistics
* Applying descriptive statistics to an employee dataset

## Tools and Libraries

* **Python** — Implementing statistical calculations.
* **NumPy** — Numerical operations and statistical functions.
* **Pandas** — Data summarization, grouping, and data-quality checks.

## Practical Skills Developed

Through these exercises, I practiced how to:

* Summarize numerical data using statistical measures.
* Understand the center and spread of a dataset.
* Interpret quartiles, percentiles, and distributions.
* Identify potential outliers and understand their effects.
* Analyze categorical data using frequencies and percentages.
* Compare numerical values across categories.
* Check datasets for missing values and duplicate rows.
* Interpret statistical results in a Data Science context.

## Why Descriptive Statistics Matters

Descriptive statistics helps transform raw data into meaningful summaries. It provides an initial understanding of a dataset and helps identify patterns, unusual values, and potential data-quality issues.

These concepts form a foundation for **Exploratory Data Analysis (EDA)** and prepare me for further study in Data Science and Machine Learning.
